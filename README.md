# UMI3D Browser (Unity)
 
UMI3D is a web protocol that enables the creation of 3D media in which users of any device (PCs, smartphones, AR and VR) can collaborate in real time. The 3D media is created once and hosted on a server or on a local computer. More information about UMI3D can be found on [its dedicated repository](https://github.com/UMI3D/UMI3D-SDK/).

The application dedicated to displaying and interacting with UMI3D 3D media is called an UMI3D Browser.
